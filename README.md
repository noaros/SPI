# SPI

After losing patience waiting for a "good" accelerometer to arrive, I ordered a cheap one, the HiLetGo BMI160. I found the pinout extremely confusing, but maybe understand it now. My interest was in the standard SPI pins, but the board used alternative names, and more than one pin looked like the same thing to me! There are differences between the chip pinout labels and the mapping to the actual breakout board. In addition the board supports I2C, and apparently has a secondary SPI interface to support output separately from the primary one. There are shared labels for all of that, with poor or hard to find documentation. One key was sleuthing that the BMI160 was very similar to the LSM6DS3 and hunting those docs. Hopefully the actual wiring will be the hardest part. I also don't have a reference tutorial for using this board, so time to leave training wheels behind.
